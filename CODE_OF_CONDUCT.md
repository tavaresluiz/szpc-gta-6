# Código de Conduta

Este projeto adota o Código de Conduta para Contribuidores. Ao participar, você concorda em respeitar as regras descritas abaixo para manter a comunidade acolhedora e profissional.

## Padrões Esperados

- Seja respeitoso e cortês com todos os colaboradores.
- Evite linguagem de ódio, discriminação ou assédio de qualquer tipo.
- Seja receptivo a feedbacks e sugestões.
- Respeite a privacidade de outros colaboradores.

## Comportamento Inaceitável

Exemplos de comportamento que não serão tolerados:

- Comentários ofensivos, insultos ou ataques pessoais.
- Assédio sexual ou linguagem sexualizada em contexto não-consensual.
- Ameaças, difamação ou divulgação de informações privadas.

## Como Reportar

Se você testemunhar ou sofrer algum comportamento inaceitável, por favor reporte abrindo uma Issue marcada como `security` ou envie uma mensagem direta para o mantenedor: https://github.com/tavaresluiz.

## Ações

Os mantenedores podem tomar medidas corretivas, incluindo avisos, remoção de conteúdo ou banimento de colaboradores, dependendo da gravidade.

## Versão

Este Código de Conduta foi baseado nos princípios do Contributor Covenant e pode ser atualizado pelos mantenedores.
