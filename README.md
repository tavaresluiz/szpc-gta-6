## Instalação e execução local
Requisitos:
- Git (opcional)
- Navegador moderno
- (Opcional) Node.js para ferramentas de desenvolvimento ou um servidor HTTP simples

Passos rápidos:

1. Clone o repositório
```bash
git clone https://github.com/tavaresluiz/szpc-gta-6.git
cd szpc-gta-6
```

2. Abrir diretamente no navegador
- Abra `index.html` no seu navegador (duplo clique ou arraste para a janela do navegador).

3. Ou servir via servidor estático (recomendado para recursos que exigem requisições)
- Python 3:
```bash
python -m http.server 8000
# Acesse http://localhost:8000
```
- Node.js (usando serve):
```bash
npm install -g serve
serve . -l 3000
# Acesse http://localhost:3000
```
